# Project 1 — приёмка исходного Word-плана

Дата: 24 октября 2026, Asia/Bishkek. Основание — `Project 1.docx`, 13 недель. Этот релиз закрывает оставшиеся SEO, локализацию, детали интерфейса, QA и подготовку презентации. Развитие бота, «Книга месяца» и настоящая занятость столов в него не включены.

## Что изменено

- Каждая публичная страница RU/EN, схема столов и форма брони имеют уникальные переведённые title/description, Open Graph, Twitter Card, canonical и взаимные `ru`/`en`/`x-default` ссылки. Карточки событий сохраняют свой ID при смене языка и получают собственные метаданные.
- Production origin задаётся существующей переменной Vercel, с текущим доменом как локальным fallback. В canonical не попадают preview-host, предпочтение стола или данные формы.
- `/sitemap.xml` включает публичные страницы и опубликованные события. Запросы идут публичным ключом, с фильтром публикации и пагинацией. Черновики, кабинет, API и стайлгайд исключены. Пустая живая таблица не подменяется демо-данными; ошибка базы не превращается в выдуманный sitemap. Маршрут динамический, поэтому публикация/удаление события отражается без пересборки.
- `/robots.txt` ссылается на sitemap и закрывает технические пути; кабинет и стайлгайд дополнительно имеют `noindex`. Это не заменяет авторизацию.
- Язык `<html>` определяется сервером из маршрута; Proxy перезаписывает внутренний заголовок. Клиентские переходы синхронизируют язык общего документа. `/booking?locale=en` также получает английский язык, вход в кабинет — русский.
- Окно 18+ переведено через словари, включая описание и обе кнопки. «Да» сохраняется в localStorage; недоступное хранилище не мешает подтвердить возраст для текущей страницы. «Нет» ведёт на нейтральный сайт. Escape не обходит подтверждение.
- Окно 18+, мобильное меню и галерея используют модальные `<dialog>`, доступные названия и управление фокусом. Tab остаётся внутри; меню/галерея закрываются по Escape. Добавлены переход к содержимому и отчётливый фокус формы.
- На главной есть ссылка со стрелкой к следующей секции, в подвале — копирайт. Добавлена векторная иконка вкладки; общий стиль и логотип сохранены.
- README переписан под реальное состояние проекта: структура, стек, env, миграции, доступ, запуск, деплой, особенности демонстрации. Подготовлен [сценарий презентации](project1-demo.md).

Новых миграций или обязательных переменных окружения нет.

## Автоматические и интеграционные проверки

- `npm test`: **232 теста**, все проходят. Новые проверки: локализованные метаданные, стабильный production canonical, взаимные языковые ссылки, исключение приватных страниц и draft-событий, пагинация sitemap, ошибки/пустая живая БД.
- ESLint и Next.js production build проходят.
- Регрессионные проверки HTTPS-адаптера Lighthouse подтверждают, что текст robots.txt и HTTP-ошибки передаются без подмены; проверка robots остаётся штатной.
- Браузерные сценарии используют production-сборку и реальный Supabase. Проверены окно 18+ RU/EN, нейтральный выход, сохранение выбора, заблокированный localStorage, модальные окна, Tab/Escape/возврат фокуса, мобильная ширина 390×844, десктоп, переводы без перезагрузки, галерея, reduced motion, ошибки формы без отправки заявки, метаданные и доступ к кабинету.
- Временный сотрудник открывает `/admin/menu`; обычный Auth-пользователь получает 403 на `/admin` и API, анонимный — вход/401. Тестовые Auth-пользователи и запись команды удалены в `finally`. Брони и Telegram-сообщения эти сценарии не создают.
- axe-core WCAG 2 A/AA и 2.1 AA: на проверенных публичных страницах и в модальных окнах нарушений не обнаружено. Автоматический аудит не заменяет ручную оценку удобства работы со скринридером.

## Мобильный Lighthouse на production

Проверен https://literator-xi.vercel.app на ревизии `8009d9d`: **16 страниц**, минимальный performance **85**, максимальный **99**. Цель исходного Word-плана **≥85 подтверждена для каждой проверенной страницы**. Accessibility, SEO и best practices — **100 на всех страницах**.

| Страница | RU performance | EN performance | Accessibility | SEO |
| --- | ---: | ---: | ---: | ---: |
| Главная | 96 | 95 | 100 | 100 |
| О нас | 92 | 97 | 100 | 100 |
| Меню | 96 | 96 | 100 | 100 |
| Афиша | 94 | 95 | 100 | 100 |
| Контакты | 95 | 85 | 100 | 100 |
| Столы | 94 | 99 | 100 | 100 |
| Бронирование | 97 | 98 | 100 | 100 |
| Карточка события | 99 | 94 | 100 | 100 |

Применён штатный мобильный профиль Lighthouse: simulated throttling, CPU slowdown ×4, чистое хранилище посетителя. Chrome for Testing 151 использует обычный сетевой прокси среды и существующее доверенное хранилище CA; TLS проверяется. Нет перехвата/подмены браузерных ответов, изменения аудитов, весов оценок или ослабления профиля. CDN-кеши могут быть прогреты предыдущими проверками. Это лабораторные результаты, не полевые Core Web Vitals и не отчёт сервиса Google PageSpeed Insights.

При проверке выявлена поздняя загрузка логотипа окна 18+: для изображения первого экрана включены eager/high priority и добавлен размер оптимизации 480px. Вспомогательный HTTPS-мост оказался непригоден для итоговой симуляции сетевой скорости; его диагностические оценки в таблицу не включены. Первоначальный локальный замер 91/100 также не используется вместо production-результатов.

Сводка с реальными метриками и настройками: [qa/project1-lighthouse-production.json](qa/project1-lighthouse-production.json). Полные HTML/JSON и снимки сохранены в рабочей среде: `/workspace/artifacts/project1-final/lighthouse-native/` и `/workspace/artifacts/project1-final/browser-native/`.

Воспроизведение: `npm run qa:browsers -- <origin>` и `npm run qa:lighthouse -- <origin>`. При необходимости укажите штатный прокси через `QA_BROWSER_PROXY`; браузеру нужен нормальный доступ к доверенному профилю сертификатов. `QA_HTTPS_BRIDGE=1` оставлен для диагностики транспортных проблем, не для финальной оценки performance. Пароли, Auth-cookie и серверные токены в отчёты не записываются.
