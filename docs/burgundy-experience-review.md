# Бордовое оформление, меню, отзывы и команда

Публичный сайт получил бордовую палитру с тёплыми текстами и золотыми акцентами. Подсветка текущего раздела и хлебные крошки показывают положение на сайте. Кнопки реагируют на нажатие; переходы сопровождаются лёгким появлением страницы и индикатором загрузки, редакторы показывают skeleton. `prefers-reduced-motion` отключает движения. Зависимости для анимации не добавлялись.

## Меню и отзывы

- Категории доступны отдельными кнопками с количеством позиций. Текущая категория выделена и объявляется через aria-pressed/status. На мобильных нет горизонтального скролла.
- Карточки в меню и на главной подписывают крепость и порцию; поля `portion_ru`/`portion_en` редактируются в кабинете. Демо-размеры явно относятся к демонстрационному меню. Миграция сохраняет уже заполненные значения.
- На странице «О нас» появилась кнопка и форма отправки отзыва: имя, оценка 1–5, текст. POST `/api/reviews` строго валидирует данные, использует honeypot и Supabase rate limit 5/600 секунд. Статус принудительно moderation; самопубликация через поля запроса невозможна. Администратор публикует отзыв через существующий редактор. Текст сохраняется на языке автора, без автоматического перевода.
- Без Supabase форма отзывов явно симулируется без POST/записи.

## Несколько администраторов

- Владелец задаётся текущими `ADMIN_USER_ID`/`ADMIN_EMAIL`, сохраняет постоянный доступ и управляет `/admin/team`.
- Закрытая `admin_members` доступна только service_role после проверки владельца. Добавленные сотрудники должны подтвердить email в Supabase Auth; они могут менять контент и заявки, но не выдавать доступ другим.
- Добавление отправляет приглашение на `/admin/reset-password`; повторная отправка и отзыв доступа доступны в кабинете. Удаляется разрешение, Auth-аккаунт и его пароль не удаляются. Новые запросы после отзыва сразу получают 403.
- Дополнительные env `ADMIN_USER_IDS`/`ADMIN_EMAILS` необязательны; для обычного управления командой менять Vercel env не требуется. Старый приоритет ADMIN_USER_ID над одиночным ADMIN_EMAIL сохранён.
- POST `/api/auth/reset-password` использует серверный Supabase SSR-клиент с PKCE-cookie и проверенным публичным origin. Есть ограничения по IP, понятная ошибка при отказе почтового провайдера и 60-секундный cooldown интерфейса. При исчерпании серверного лимита интерфейс учитывает Retry-After вместо предложения повторять запрос каждую минуту. Успешный ответ подтверждает приём запроса сервисом; папку входящих пользователя сервис не контролирует.
- Страница установки пароля принимает и recovery, и invite ссылки. Вход показывает понятное сообщение при отсутствии прав.

## Миграция

`supabase/migrations/20261015000100_0004_menu_and_team.sql`, применена владельцем на Supabase. Добавляет размеры порций и приватную таблицу команды с RLS и отозванными браузерными правами. `schema.sql` синхронизирован. Персональные адреса не зашиты в исходники или SQL.

## Проверка

- 146 тестов проходят, lint и production build успешны. Проверены схемы отзывов, принудительная модерация, honeypot/rate limit, owner-only API команды, недоступность таблицы браузерным ролям, отзыв доступа, ошибки отправки почты и повторяемость SQL без потери порций.
- Браузер с живым Supabase: публичный отзыв скрыт до модерации, публикация видна в EN, удаление работает; шестая отправка блокируется. Владелец и второй временный администратор имеют доступ, второй не может управлять командой, после удаления разрешения получает 403. Временные пользователи, отзывы, позиция меню и разрешение очищены.
- Браузер без Supabase: категории, крепость/порции, подсветка и хлебные крошки, 390px без горизонтального скролла, отзыв без сетевых POST, отключённые анимации при reduced motion.
- Запрос восстановления для владельца и приглашение указанному сотруднику приняты Supabase с HTTP 200. Пароли не задавались и не изменялись агентом.
- Настоящая invite-сессия временного Supabase Auth-пользователя проверена браузером: установка нового пароля, удаление токенов из URL и успешный password login. Временный аккаунт удалён.
- Мобильный Lighthouse на production-сборке с живым Supabase: меню performance 90/accessibility 100; «О нас» performance 88/accessibility 100. Это измерения облачной среды, не Vercel.

Изображение нового логотипа в сообщении отсутствовало. Точная замена по образцу остаётся до получения файла; остальной дизайн подготовлен независимо от него.
